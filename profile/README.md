# Dasgar Studio

Independent software development focused on **local-first**, **offline-capable** desktop tools built around human-readable files, zero telemetry, and full user ownership.

## Featured Project: MediaVault

A private, local-first media library and cataloging desktop application for **Windows 10 / Windows 11 (64-bit)** built around plain Markdown files with YAML frontmatter, an AES-256-GCM encrypted private vault, customizable themes, multi-language support, and sandboxed plugins.
